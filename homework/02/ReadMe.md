### Learning Outcome Guides (LOGs)

*At the end of this self-study, you should be able to*

1. Use arithmetic operators, modulo, and `Math` functions to solve numeric problems.
1. Create and call simple reusable functions that accept parameters and return calculated values.
1. Round and format numeric results using `Math.round()` and `.toFixed()`.
1. Convert text values into numbers with `parseInt()` and `parseFloat()`, including cases that produce `NaN`.
1. Clean, transform, and format strings using properties and methods such as `.length`, `.trim()`, `.toUpperCase()`, `.toLowerCase()`, `.padStart()`, `.padEnd()`, and `.replaceAll()`.
1. Combine numbers and strings to produce aligned, readable console output.
