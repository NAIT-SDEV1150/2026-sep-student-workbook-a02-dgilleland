### Learning Outcome Guides (LOGs)

*At the end of this self-study, you should be able to*

1. Demonstrate how and when to attach and remove event listeners on controls inside a custom element.
2. Identify the callback function names that the browser looks for when managing component lifecycle. 
3. Manage internal state changes in a custom element.
4. Communicate internal state changes by dispatching custom events.
