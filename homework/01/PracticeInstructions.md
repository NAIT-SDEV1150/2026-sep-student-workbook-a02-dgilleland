# Learn Markdown

Markdown and version control appear **everywhere** in software development. In this self-study homework assignment, you will explore and practice both.

## More Markdown - Keeping Organized ![Self-Study](https://img.shields.io/badge/Code%20Status-Self--Study-blueviolet?logo=Visual%20Studio%20Code&labelColor=indigo)

> :black_nib: Remember to jot down things you've learned from this self-study in your [homework notes](./Notes.md).

This course is mainly about learning JavaScript as a beginner. Even so, Git, GitHub, VS Code, the terminal, and Markdown are part of the working environment we use to write and submit code. They are not the main subject of the course, but the effort you put into learning them will help you in this course and in your other programming courses.

The goal of this self-study is to help you organize Markdown content so that it has more value: images, links to other documentation in your repository, notes you can return to later, and commits that preserve your work.

## Your Task

1. Read and bookmark this page on [Writing GitHub Flavored Markdown](https://docs.github.com/en/get-started/writing-on-github/getting-started-with-writing-and-formatting-on-github/about-writing-and-formatting-on-github).
1. Create a `docs/images/` folder in the root of your repository.
1. Download an image from the article above, and place it in the [`docs/images`](../../docs/images/) folder you just created. Make an entry in your [homework notes](./Notes.md) in which you demonstrate referencing that image in Markdown. Also include a fenced code block in your notes showing the Markdown code used to reference that image.
1. Create a [QR Code of your name](https://www.the-qrcode-generator.com/) and save it as an image to the [`docs/images`](../../docs/images/) folder. In the [`README.md`](../../README.md) at the root of your repository, add that image on a separate line just below the first Markdown level-1 heading.
1. Edit the root [`README.md`](../../README.md) document to add a table for each week of classes. In this table, place links to each homework assignment's **ReadMe** file. As you create the Markdown links, use **relative paths** when linking to items inside your repository.
1. Review the starter notes in [`Markdown.md`](./Markdown.md) and [`git+VSCode.md`](./git+VSCode.md). These files are intentionally thin right now. Expand them with useful reminders, examples, commands, links, and questions as you practice these topics throughout the term.
1. Commit these changes to your repository and synchronize them with the copy on GitHub. View these pages on GitHub to see how the links and images appear.

The [Notes.md](./Notes.md) file is intentionally empty. Use it as a place for notes specific to this homework assignment. It is also a good place to write down questions for your instructor, either so you remember to ask in the next class or so you can point your instructor to the question in a direct message outside of class.

## Before You Finish

Check your work before you submit it:

- The `docs/images/` folder exists in the root of your repository.
- Your downloaded image is saved in `docs/images/`.
- Your [homework notes](./Notes.md) show the image and also show the Markdown code used to reference it.
- Your generated QR code image is saved in `docs/images/`.
- The root [`README.md`](../../README.md) displays the QR code image just below the first level-1 heading.
- The root [`README.md`](../../README.md) includes a table with relative links to homework **ReadMe** files.
- You have expanded [`Markdown.md`](./Markdown.md), [`git+VSCode.md`](./git+VSCode.md), or [Notes.md](./Notes.md) with useful notes from this self-study.
- Your changes are committed, pushed, and visible on GitHub.

Feel free to augment any of these Markdown files with additional information that you have learned in class.

### Learning in the Age of AI

Tools such as ChatGPT can help you investigate topics when you are studying on your own. They are especially useful when you have a specific question, a command you want explained, or an example you want to compare with your own work.

> ⚠️ **WARNING:** While you are encouraged to use AI to help you learn, you are *not* permitted to use AI on your for-marks assignments in this course. Using AI on for-marks assignments is considered **academic misconduct**.

In this workbook, I have provided you with numerous "Learning Outcome Guides" (*LOGs*) which identify specific items you should be able to demonstrate after each lesson. If you want to learn more about any of these items, you can use ChatGPT to help. For example, you could enter the following prompt:

> **Prompt:** ["How do I configure git to use my name and email address?"](https://chat.openai.com/share/80dd999f-6bbc-4b54-ad32-631c13da180d)

When you use AI tools, make sure you still do the work yourself. Your goal is not only to get an answer, but to understand the answer well enough that you can use the idea again later.
