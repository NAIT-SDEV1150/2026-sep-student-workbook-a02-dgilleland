### Learning Outcome Guides (LOGs)

*At the end of this self-study, you should be able to*

#### VS Code and Version Control

1. Describe what is meant by "version control"
1. Identify the version control system used in this course
1. List the three primary states of a file in Git
1. List seven of the most common Git commands
1. Configure Git to use your name and email address
1. Explain the purpose of the `.gitignore` file
1. Create and synchronize commits as a means of submitting your work
1. Describe the purpose and basic principles of Markdown syntax
1. Create notes written in Markdown format
1. List four common commands used in the terminal
1. Identify the keyboard shortcuts for opening the terminal inside and outside of VS Code
1. Identify the keyboard shortcut to open the command palette in VS Code
1. Perform basic tasks in the terminal related to navigation and version control

#### Markdown

1. Create headings and subheadings in Markdown
1. Create ordered and unordered lists in Markdown
1. Create checkbox lists in Markdown
1. Create links in Markdown
1. Embed image links in Markdown
1. Create tables in Markdown
1. Create inline code blocks in Markdown
1. Create fenced code blocks in Markdown for specific languages
1. Search your repository on GitHub to find or recall information
