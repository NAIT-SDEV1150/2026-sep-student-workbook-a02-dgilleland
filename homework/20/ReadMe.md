### Learning Outcome Guides (LOGs)

*At the end of this self-study, you should be able to*

1. Describe the difference between public and private members of a class
2. Describe the difference between regular properties of a class and getter/setter properties of a class
3. Describe the difference between getter/setter functions and regular functions
4. Describe the difference between `static` and non-`static` members of a class
5. Describe the purpose of the class constructor
6. Explain the role of JavaScript "prototype chain" with regard to objects and classes
7. Extend an object's underlying prototype using the `.__proto__` property
8. Explain the concept of inheritance in JavaScript
9. Demonstrate the use of private/public members along with properties/functions in a class
10. Demonstrate the use of static and instance members of a class
11. Demonstrate class inheritance
