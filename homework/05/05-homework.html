When we already know the opposite side and the hypotenuse, JavaScript’s Math.asin() function can calculate the angle in radians.

Trigonometry Refresher

The regular Math.sin() function starts with an angle and tells us the sine ratio. In this function, we are working in the opposite direction: we already know the ratio opposite / hypotenuse, and we want JavaScript to tell us the angle.

That is why we use Math.asin(). The a stands for arc sine, which is another name for inverse sine. Inverse sine answers the question: “What angle has this sine ratio?”

Conclusion

Section titled “Conclusion”

You’ve now practiced writing practical functions that calculate and return useful values. The important idea is not just the trigonometry, the loan formula, or the time conversion. The important programming pattern is that each function receives input, does one focused calculation, and returns a result that other code can use.

You also practiced composing functions by calling toDegrees() and toGradians() from inside the angle functions. That helper-function pattern is one of the ways we keep programs easier to read and easier to maintain.

Understanding JavaScript

Functions become more useful when they return values instead of only printing output. A returned value can be tested, stored, passed into another function, or combined with other values later in a program.
