Guided Self-Study Tutorial

Section titled “Guided Self-Study Tutorial”

In the previous lessons, we started using Node project tooling for frontend work and then used JavaScript to select and update HTML elements in the browser. In this self-study tutorial, we’ll put those two ideas together.

We’ll set up the practice/ folder as a Vite project, connect index.html to js/main.js, calculate a few assignment bucket marks, and then use helper functions in js/browser-ui.js to display the results on the page.

The Starter Project

Section titled “The Starter Project”

Before we change anything, let’s orient ourselves to the files.

  • index.html provides the page structure and the placeholder elements we will fill from JavaScript.
  • js/main.js coordinates the calculation work and asks the browser UI helpers to render the result.
  • js/browser-ui.js contains helper functions for selecting and updating DOM elements.
  • js/bucket-calculator.js is already complete. It stores bucket marks and calculates the visible grade summaries.
  • css/styles.css is already complete. It includes the heading classes that browser-ui.js will apply.

One Project, Several Responsibilities

This homework is intentionally split across modules.

The calculator module handles grade math. The browser UI module handles DOM updates. The main module connects those pieces together.

The first argument is an element id. The second argument is the text to put inside that element.

  1. Find the starter function.

  2. Rename the parameter to selector if you want it to match the intended helper shape.

  3. Guard against missing values, select the element by id, and assign its text.

    Notice that main.js also calls ui.print(); with no arguments. This guard keeps that call from causing an error.

Selector or ID?

The parameter name selector is not perfect here because document.getElementById() expects an id value without #.

For this homework, follow the helper call shape already used in main.js: ui.print('trending', stats.trending).

Understanding JavaScript

The important habit here is to keep responsibilities clear.

If a value needs to be calculated, look for the calculator module. If the page needs to change, look for the browser UI module. If the application needs to coordinate the work, look in the main module.
