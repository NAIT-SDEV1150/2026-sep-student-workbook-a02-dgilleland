This homework is part of a larger assignment that is worth marks. Please review the [**LOGs**](#learning-outcome-guides-logs) and the [**reading links**](#reading-links) associated with this self-study.

The instructions for this assignment are in the [25-homework.html](./25-homework.html); you can view it using VS Code's [Integrated Browser](https://code.visualstudio.com/docs/debugtest/integrated-browser#_open-the-browser). >

### Learning Outcome Guides (LOGs)

*At the end of this self-study, you should be able to*

1. Assemble and test advanced custom elements which coordinate their behaviours.
1. Justify the use of `async` test cases when testing custom elements. 
1. Implement asynchronous unit tests.
1. Explain the purpose and necessity of mocks and spys in unit tests.
1. Implement a simple spy in a unit test.
