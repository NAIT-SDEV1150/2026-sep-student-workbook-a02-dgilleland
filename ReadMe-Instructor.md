# Instructor Notes

This is a **Formative Assessment** that is intended to reside inside the **Student Workbook**. It is not automatically part of the [Student Workbook Template](https://github.com/NAIT-SDEV1150/workbook-template). Rather, the contents of this template are to be added/applied to the student workbook via `*.patch` files and pull requests. See the [core repository docs](https://github.com/SDEV-NAIT/SDEV1150) for notes on distributing this starter kit's files.
