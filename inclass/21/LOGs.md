# Intro to Custom Elements (Web Components)

*At the end of this lesson, you should be able to*

1. Define and register a custom element with `HTMLElement` and `customElements.define()`.
1. Build a reusable component with a template, Shadow DOM, and scoped internal markup.
1. Pass content and simple configuration into a custom element with slots and attributes.
1. Create custom elements in a web page declaratively.
1. Create custom elements in a web page programmatically.
1. Distinguish autonomous custom elements from customized built-in elements.
1. Apply custom-element naming rules when defining a new element.
1. Explain why custom element constructors should stay focused on initial setup.
1. Use default and named slots to place light-DOM content inside a component template.
