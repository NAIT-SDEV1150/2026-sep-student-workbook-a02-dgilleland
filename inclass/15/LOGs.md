# Event Listeners

*At the end of this lesson, you should be able to*

1. Explain the concept of event-driven programming in the context of web development.
1. Identify common browser events (e.g., click, mouseover, keydown).
1. Use JavaScript to respond to common browser events and dynamically update DOM content.
1. Distinguish between `.target` and `.currentTarget` on event objects.
1. Utilize event propagation techniques, including event bubbling and capturing.
1. Explain how bubbling, capturing, and delegation affect event handling.
