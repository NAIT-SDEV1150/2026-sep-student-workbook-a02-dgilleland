The focus of this lesson expands on **Custom Elements** in vanilla JavaScript through the use of internal state management, public methods/properties on the custom element class, lifecycle callbacks, and event dispatching. The details of the lesson will be covered in class, because this lesson is part of a larger assignment that is worth marks. In preparation for the in-class lesson delivery, you should review the [**reading links**](#reading-links) associated with this lesson.
