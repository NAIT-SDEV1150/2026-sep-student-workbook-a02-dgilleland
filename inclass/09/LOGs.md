# JavaScript Modules - Import, Export, and JSDocs

*At the end of this lesson, you should be able to*

1. Export variables and functions using the `export` keyword.
1. Import variables and functions using the `import` keyword.
1. Apply JSDoc comments to exported functions and variables to support in-editor intellisense.
1. Explain the benefits of modularizing script files using ES Modules.
1. Explain the concept of module scope with JavaScript modules.
