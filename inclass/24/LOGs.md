# Unit Testing Fundamentals

*At the end of this lesson, you should be able to*

1. Explain the role of automated testing in software development.
1. List the benefits of automated tests.
1. List common kinds of automated tests, including unit, integration, end-to-end, and manual exploratory testing.
1. Explain the basic tenets of test-driven development.
1. Set up a basic Vitest test environment for Node-based JavaScript modules.
1. Write unit tests for JavaScript modules using `describe`, `it` or `test`, `expect`, and the Arrange-Act-Assert pattern.
1. Execute and interpret test results for spec development, debugging, and regression checking.
1. Explain the concept and value of test coverage.
1. Explain what test coverage measures and why coverage numbers do not prove that code is correct.
