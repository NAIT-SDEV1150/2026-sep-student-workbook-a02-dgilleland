# JavaScript Intro + Version Control

*At the end of this lesson, you should be able to*

1. Create and update variables using `let`, `const`, assignment, and compound assignment.
1. Build readable output using string concatenation and template literals.
1. Perform arithmetic calculations with numeric values and format decimal results with `.toFixed()`.
1. Convert string input into numbers using `parseInt()` and `parseFloat()`.
1. Use `typeof` to inspect values and explain how JavaScript treats strings and numbers differently.
