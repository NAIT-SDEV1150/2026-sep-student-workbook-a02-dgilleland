# DOM Manipulation

*At the end of this lesson, you should be able to*

1. Use `.querySelectorAll()` to select multiple elements matching a particular query string.
1. Compare and contrast Node collections and arrays.
1. Determine if an attempt to select element(s) from the DOM has failed.
1. Select elements from a subset of the DOM.
1. Navigate from a selected element to parent, child, and sibling elements.
1. Create and insert new HTML elements into a page using the DOM API.
1. Use `document.createElement()` to create new element nodes.
1. Compare `.textContent` with `document.createTextNode()` for adding text.
1. Modify image attributes such as `src`, `alt`, and `width`.
1. Traverse the DOM tree to select parent, child, and sibling elements.
1. Remove and replace elements dynamically within the DOM.
1. Explain the relationship between document fragments and the DOM.
