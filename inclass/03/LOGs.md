# Primitive Types vs. Simple Objects

*At the end of this lesson, you should be able to*

1. Distinguish primitive values such as strings, numbers, and booleans from object values.
1. Use `typeof` to inspect the data type of values in a running script.
1. Create object literals that group related values into a single variable.
1. Read object properties using dot notation and combine those properties with expressions and template literals.
1. Add new properties to existing objects and update existing property values.
1. Create and use built-in objects such as `Date` and `URL`.
1. Call object methods to retrieve, format, or change information stored inside objects.
