# Understanding Functions

*At the end of this lesson, you should be able to*

1. Define reusable functions using both function declaration syntax and function expression syntax.
1. Use parameters to receive input values and pass arguments when calling a function.
1. Return calculated or formatted values from a function.
1. Use returned values from functions in variables, expressions, and later function calls.
1. Pass one function into another function so it can be called as part of a larger operation.
1. Return a function from another function.
1. Explain how a returned function can remember and update state from the function that created it.
