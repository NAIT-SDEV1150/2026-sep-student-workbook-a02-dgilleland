# Repetition - Flow Control Intro

*At the end of this lesson, you should be able to*

1. Explain how repetition extends flow control beyond simple sequence and conditional branches.
1. Use a `while` loop when repetition depends on a condition becoming false.
1. Use a `for` loop when the number of repetitions is known or tied to indexes.
1. Update loop-control variables so a loop moves toward its stopping condition.
1. Use accumulator variables to build totals, counts, or output during repetition.
1. Combine loops with `if` statements to respond to selected values during repetition.
1. Use nested loops for repeated work that has rows, columns, or grouped data.
