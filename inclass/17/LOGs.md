# Browser Debugging Tools

*At the end of this lesson, you should be able to*

1. Demonstrate how to access and use browser developer tools for debugging JavaScript.
1. Interpret console error messages to identify code issues.
1. Apply breakpoints and step-through code execution to isolate bugs.
1. Explain the use of the `debugger` statement in JavaScript.
1. Explain how the Network tab in the browser developer tools relates to the rendering activities of the browser.
