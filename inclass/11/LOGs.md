# JavaScript and HTML - Intro

*At the end of this lesson, you should be able to*

1. Explain how HTML, CSS, and JavaScript work as three distinct languages in front-end development.
1. Create a simple Node-based web project using HTML, CSS, and JavaScript.
1. Utilize the console for testing code snippets and exploring variable values.
1. Explain the role of the DOM in web development.
1. Select and manipulate HTML elements using JavaScript.
1. Distinguish between class, tag, id, and element selectors in `.querySelector()`.
1. Modify content, attributes, and styles through DOM methods.
