# Consuming REST API Endpoints

*At the end of this lesson, you should be able to*

1. Guard API calls with appropriate HTTP status checks and content-type checks.
1. Perform `PUT`/`PATCH` and `DELETE` requests on a REST API.
1. Demonstrate how to use the fetch API for non-JSON requests.
1. Demonstrate the ability to synthesize data requests from multiple API calls.
