# Arrays as a Structure

*At the end of this lesson, you should be able to*

1. Create arrays that store related values such as strings, numbers, and booleans.
1. Use the `.length` property to determine how many entries are stored in an array.
1. Access array entries with zero-based indexes and identify the first and last valid indexes.
1. Update existing array entries and add new entries using bracket notation.
1. Keep related arrays aligned by using the same index position across each array.
1. Use `Array.isArray()` to distinguish arrays from other object values.
1. Compare array indexing with object dot notation and object bracket notation.
1. Explain why out-of-bounds array access returns `undefined`.
1. Store objects inside an array and access nested object properties through an array index.
