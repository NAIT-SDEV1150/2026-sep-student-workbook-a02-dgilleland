# If-Else - Flow Control Intro

*At the end of this lesson, you should be able to*

1. Write a basic `if` statement that executes code only when a condition is true.
1. Use relational expressions such as `>` and `>=` to make simple decisions.
1. Explain how changing variable values can change which code path runs.
1. Use `if`/`else` statements to create alternate paths of logic.
1. Place multiple statements inside a decision block with curly braces.
1. Assign different values inside different branches of an `if`/`else` statement.
1. Combine the results of independent decisions in later calculations and output.
