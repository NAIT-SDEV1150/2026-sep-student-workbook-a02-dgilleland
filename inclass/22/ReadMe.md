## Demo Instructions

![Static Badge](https://img.shields.io/badge/Assignment%204-In--Class%20Bucket-blue?style=for-the-badge&logo=javascript)

The focus of this lesson expands on **Custom Elements** in vanilla JavaScript by addressing Shadow DOM styles, host styling hooks, slotted content styling, externally configurable CSS custom properties, and the `::part` pseudo-class. The details of the lesson will be covered in class, because this lesson is part of a larger assignment that is worth marks. In preparation for the in-class lesson delivery, you should review the [**reading links**](#reading-links) associated with this lesson.

> ### Automated Tests

> ```
