# Styling Custom Elements

*At the end of this lesson, you should be able to*

1. Explain how Shadow DOM affects style encapsulation for custom elements.
1. Use `:host` and CSS custom properties to define component styling hooks.
1. Identify common stylistic concerns that are appropriate to expose through `:host` styles. 
1. Respond to attribute changes with `observedAttributes` and `attributeChangedCallback()`.
1. Explain which styles are scoped inside a shadow root and which styles can still affect the host element.
1. Use `:host` and `:host()` to style a custom element from inside its shadow DOM.
1. Use `::slotted()` to style light-DOM content assigned to a slot.
1. Identify when a component should expose styling hooks with CSS custom properties or `::part`.
