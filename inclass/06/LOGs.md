# Creating and Using Objects

*At the end of this lesson, you should be able to*

1. Describe object values using `typeof` and their constructor names.
1. Create object literals for simple, one-off structured data.
1. Define constructor functions that initialize object properties with `this`.
1. Create object instances with the `new` keyword.
1. Add shared methods to a constructor function's prototype.
1. Define classes using class expression syntax and class declaration syntax.
1. Use class constructors to initialize instance properties.
1. Add and call instance methods that read or change an object's state.
