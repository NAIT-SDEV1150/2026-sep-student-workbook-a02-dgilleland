# More If-Else

*At the end of this lesson, you should be able to*

1. Use relational operators such as `<`, `>=`, and `===` in conditional expressions.
1. Compare general equality with strict equality using `==` and `===`.
1. Use strict inequality with `!==` to detect differences in value or data type.
1. Combine conditions with logical operators such as `&&`, `||`, and `!`.
1. Use `else if` chains to choose one result from several possible branches.
1. Call functions inside conditional expressions to make decision logic easier to read.
1. Explain how truthy and falsy values affect whether an `if` statement runs.
