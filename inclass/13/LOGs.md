# Looping with Arrays

*At the end of this lesson, you should be able to*

1. Loop through arrays by index using a `for` loop.
1. Read array values with indexes and use `.length` to control repetition.
1. Use manual loops to build totals, counts, and selected values from an array.
1. Write arrow functions for array-method callbacks.
1. Choose between `.forEach()`, `.map()`, `.find()`, `.findIndex()`, `.filter()`, `.slice()`, `.splice()`, and `.sort()` for common array tasks.
1. Use `.forEach()` to run code once for each array item.
1. Use `.map()` to transform each array item into a new value.
1. Use `.find()` and `.findIndex()` to locate one matching item or position.
1. Use `.filter()` to produce a new array containing matching items.
1. Use `.slice()` to copy part of an array without changing the original array.
1. Use `.splice()` to remove or insert array items by changing the original array.
1. Use `.sort()` with a compare function to order strings and numbers predictably.
