# Node Projects for Frontend Development

*At the end of this lesson, you should be able to*

1. Initialize a new Node.js project from the command line.
1. Explain the purpose of `package.json` in a JavaScript project.
1. Install, update, and remove project packages with a package manager.
1. Distinguish between regular dependencies and development dependencies.
1. Use package scripts to run common project commands.
1. Use ES Module `import` and `export` syntax to organize JavaScript code.
1. Identify the purpose of the `<script>` tag and how to use it to import ES Modules.
1. Demonstrate logging messages to the browser's Developer Tools Console.
1. Build a small frontend page that imports and uses code from project dependencies.
