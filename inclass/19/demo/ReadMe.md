# Lesson 20 Demo: Fetch API Calls

This starter demo runs a Vite front end and JSON Server backend together. The browser page will use `fetch()` to load and add celestial bodies.

## Setup

1. Install dependencies with `pnpm install`.
1. Run the front end and backend together with `pnpm dev`.
1. Smoke-test the backend with `api-smoke-test.http`.
1. Open the Vite URL in the browser.
1. Complete the TODOs in `js/utils.js` and `js/main.js`.
