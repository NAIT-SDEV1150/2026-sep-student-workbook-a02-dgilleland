# HTTP and Server-Side Endpoints

*At the end of this lesson, you should be able to*

1. Explain how REST-style APIs support front-end applications and data-driven UI.
2. Set up and run JSON Server to simulate REST API endpoints.
3. Compare and contrast GET, POST, PUT/PATCH, and DELETE requests.
4. Demonstrate how to test REST API endpoints using `.http` files.
   1. *([Requires VS Code extension](https://marketplace.visualstudio.com/items?itemName=humao.rest-client))*
5. Perform GET, POST, PUT/PATCH, and DELETE requests using a REST client and the browser, and interpret responses.
